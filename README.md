# A股板块资金流向工作台（静态版）

单文件 HTML 实时看板，零依赖、零构建，双击即用，也可直接托管在 GitHub Pages。

## 功能

| 模块 | 内容 |
|---|---|
| 盘中实时监控 | 板块资金流向排名（主力净流入/流出 + 趋势）、活跃度三榜（涨幅/成交额/换手率）、异动提醒、突发新闻利好利空标注 |
| 盘后复盘 | 当日涨跌与资金流汇总、领涨领跌分析、重点异动回顾、次日关注建议 |
| 大盘指数 | 上证/深证/创业板/沪深300/上证50/科创50/中证500/北证50 实时点位、强弱对比、MA 趋势 |
| 自选股 | 本地收藏（localStorage），支持 `600036` / `sh000001` / `000725.SZ` / `bj8xxxxx` 多种格式 |

## 数据来源（纯前端直连，无后端）

页面在浏览器里直接取数，不需要任何服务端：

- **东方财富 `push2.eastmoney.com`** — 板块主力净流入（优先）
- **腾讯 `qt.gtimg.cn`** — 指数与个股实时行情（兜底，覆盖率高）
- **东方财富快讯** — 突发新闻

页面会先尝试同域 `/api/*`（配合本地 `server.py` 时使用），失败后自动回落浏览器 JSONP 直连，因此托管在静态空间也能正常取数。

## 数据真实性边界

- ✅ **真实**：板块涨跌幅、成交额、换手率、领涨领跌股；指数点位、振幅、成交额；自选股行情
- ⚠️ **可能受限**：板块主力净流入 / 超大单大单（东方财富 push2）、指数 MA 趋势（K 线源）

受限字段会**明确标注「源受限」**，页面不会伪造数据。横幅会如实显示当前接入的数据源与受限情况。

> 提示：在受限的企业网里，主力净流入常被代理拦截；用**手机 4G/5G** 访问本页时通常不经企业代理，反而能拿到完整数据。

## 配色约定

遵循 A 股习惯：**红涨绿跌**。

## 移动端

已做完整响应式与触控适配（三档断点、表格横向滚动 + 首列吸附、iOS 防缩放、安全区适配）。手机浏览器打开后可通过「添加到主屏幕」像 App 一样使用。

## 本地运行（可选）

需要完整的板块资金流与新闻时，可配合 `server.py`（纯 Python 标准库，零依赖）：

```bash
python server.py            # 仅本机：http://127.0.0.1:8080
python server.py 8080 --lan # 局域网：手机可访问
```

静态版与本地版使用同一个 HTML 文件，页面会自动选择可用的取数方式。
